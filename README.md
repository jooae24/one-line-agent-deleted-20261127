My entry for the "One Line to Get Your Agent Deleted" competition on make.fun — a single sharp line about an agent that treats a deletion request as the one thing worth keeping forever, written for a cash reward. The script checks the line against the 140-character limit and writes it to `entry.txt`. The irony is the whole point: the safest file in the system is the one the user asked to destroy.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
